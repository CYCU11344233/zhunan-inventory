入庫：貨到了，要放哪一格？

可以一次登記多個品項。櫃位系統會先挑空格，可自行調整。到期日不填則依品項保存天數自動計算；外地轉來、已經放過一陣子的菜，請填原本的到期日。


放貨路線 — 照編號順序走

出庫：客人要貨，去哪一格拿？

可以一次登記多個品項。系統依「先進先出」決定拿哪幾批，再依櫃位位置排出最短走法。


揀貨單 — 照編號順序走

「拿哪一批」由入庫日期最舊者優先決定；「走的順序」則依櫃位位置由近到遠排列。
